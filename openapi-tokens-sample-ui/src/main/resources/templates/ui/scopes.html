Справочник скоупов

Все известные скоупы с описанием и правами, которые они выдают. Источник данных — GET /api/openapi/scopes (конфиг openapi.tokens.scopes.catalog + таблица scope_catalog).

режим: identity

В режиме identity имя скоупа выдаётся как authority напрямую (колонка «Даёт права» остаётся пустой), в режиме mapped скоуп проецируется в набор project-authorities из openapi.tokens.scopes.mappings и таблицы scope_mapping.
